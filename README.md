# BuildPath Admin

Internal administration interface for BuildPath.

## Current scope

The initial page defines the console boundary and planned work areas: capability catalog, quality profiles, and operations/audit. It exposes no project data or control actions before staff authentication, permissions, and audit APIs exist.

## Local development

Requires Node.js 22.11+.

```sh
npm install
npm run dev
```

See [builder-docs](https://github.com/nurgeldiserikbay/builder-docs) for product and security requirements.
